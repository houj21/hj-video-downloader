# 本地视频总结 · 设计文档

> 版本 v1.0 ｜ 2026-11-23
> 范围：总结页新增「本地视频」来源——上传本地视频/音频 + 字幕，走与在线视频相同的 AI 总结管线。

## 一、需求与决策

| # | 决策项 | 结论 | 来源 |
| --- | --- | --- | --- |
| D1 | 转写方案 | 不做 ASR：本地视频自带字幕（外挂文件或容器内封字幕轨），直接提取 | 用户确认「本地视频有字幕文件」 |
| D2 | 上传上限 | 1GB（UPLOAD_MAX_BYTES 环境变量可覆盖） | 用户选择 |
| D3 | 权益 | 终身会员专属（与在线视频总结一致） | 用户选择 |
| D4 | 字幕来源优先级 | 外挂字幕文件 > ffmpeg 提取内封字幕轨 > 明确报错 | 推论 |

明确不做：语音转写（硬字幕视频无法总结，报错信息引导提供字幕文件）。

## 二、字幕获取链路

- 有外挂字幕（.srt/.vtt/.ass/.ssa）: 直接解析（新增 ASS/SSA 解析器）
- 无外挂字幕: ffprobe 探测字幕流
  - 有文本字幕流（subrip/ass/ssa/mov_text…）: ffmpeg -map 0:s:N 提取为 srt
  - 只有图形字幕流（PGS/DVD）: 报错「图形字幕无法提取，请提供外挂字幕」
  - 无字幕流: 报错「未找到可用字幕……」
- 解析 cues: 复用 _finish_summary（时间轴 → LLM 总结 → 导图/追问/导出全链路复用）

标题取用户原始文件名（服务端落盘是 UUID，展示层不能用）；时长用 ffprobe，失败则用字幕末条时间轴推算。
ASS 解析要点：[Events] 段 Format: 声明字段序，Dialogue 按字段数定长拆分（Text 是最后字段，可含逗号）；时间 H:MM:SS.CS 百分秒；样式标签由 clean_cue_text 清理。

## 三、接口

POST /api/summarize/upload（multipart，@membership_required）

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| video | 是 | mp4/mkv/mov/avi/webm/flv/ts/m4v/wmv/mp3/wav/m4a/aac/flac/ogg/opus |
| subtitle | 否 | .srt/.vtt/.ass/.ssa（≤10MB） |

成功 200 {job_id}；未登录 401 / 非会员 403；缺文件或扩展名非法 400；超过大小上限 413。
流式落盘：_save_upload 按 1MB 分块写 + 实时计数，不读入内存；UUID 重命名防路径注入。
任务结束（成功/失败）finally 删除上传文件；服务启动时清空 uploads/ 残留。
进度：上传阶段由前端 XHR progress 渲染（0-45%），任务阶段复用现有轮询。
追问、字幕查看/TXT/SRT 下载、MD/Word/PDF 导出、思维导图——全部基于 job_id 复用，零额外改动。

## 六、已知边界

- 纯硬字幕（字幕烧进画面）的本地视频无法总结，会得到明确错误提示。
- 图形字幕（PGS/DVD，字幕是图片）无法提取文本，报错引导提供外挂字幕。
- 上传耗时取决于本地环回带宽（1GB 通常数十秒内）；转写/ASR 为后续可选二期。
